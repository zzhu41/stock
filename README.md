## 策略规则

1. **牛熊体制**：沪深300ETF 在 MA250（年线）上方 = 牛市；下方 = 熊市，A股池无条件离场
2. **竞赛池**：牛市 = 7只A股 + 2只跨境；熊市 = 2只跨境 + 黄金（与A股低相关资产在熊市继续参赛）
3. **排名**（v8 变更）：score = **25 日时间加权回归斜率 ÷ VOL20**（回归用全路径抗噪、近期权重更高；取代 v7 的 MOM20÷VOL20 首尾比值）；第一名且 MOM20 > 0 → 持有；**挑战者须 MOM20 超持仓一定幅度才换（分池缓冲 v9.1：A股 2% / 跨境 3% / 黄金 3%**——QDII 趋势持续+溢价噪声大，黄金咬避险趋势）
4. **离场**：持仓 MOM20 转负 → 当日离场
5. **急跌离场**（v6 新增）：持仓单日跌幅 ≤ -4% → 当日离场；次日若仍动量第一可立即买回（无冷却，卖飞成本有限）。本质是连续崩盘的左尾保险，不是阿尔法
6. **过热快离场**：持仓 MOM20 > +40% 时，改用 MOM5 转负即走（防抛物线顶）
7. **轮动缓冲**：挑战者 MOM20 须超出现持仓 2 个百分点才切换
8. **永不空仓**（v7 新增）：竞赛池无人达标 → 牛市先看黄金备胎（MOM20>0），再不行就持**避险池（纳指/创新药/黄金）score 最强者**，不蹲货币。逻辑：它们与 A股低相关，股票全灭时大概率比干等强。代价：全负动量年（2022）多亏约 4pp、无人达标密集期操作明显变频繁
9. **备胎**：仅当 NEVER_EMPTY 关闭时，兜底才是货币ETF

⚠️ **QDII 溢价提示**：买纳指ETF(513100)等 QDII 前看一眼溢价率（雪球/集思录），>2% 不要追，等回落。

9. **恐慌抄底**（v9 新增，危机 Alpha）：任何标的 **MOM5 ≤ -8% 且低于年线 20%**（深跌恐慌）→ 当日抄底买入并**锁仓 5 个交易日**（锁仓状态存 `signals/crash_lock.json`，期内信号强制持有）；9 年不触发、触发年大赢（2015 +55pp、2022 +18pp、2024 +23pp）

## 部署配置

钉钉推送依赖两个本地文件（均已 gitignore，不入库）：

- `data/dingtalk.webhook`：钉钉机器人完整 webhook URL（含 access_token），一行，必填
- `data/dingtalk.secret`：加签密钥（SEC 开头），可选；不配则退回关键词验证模式

行情数据（`data/*.csv`）由 `market_data.py` 从腾讯接口自动增量下载并缓存，无需手动准备。

## 每日流程

1. **14:50**（交易日）：cron 自动生成信号 → `signals/latest.txt`，并**自动推送到钉钉群**（markdown 卡片）
2. **14:50-15:00** 按建议操作（尾盘成交，与信号价最接近；用限价单贴价，滑点 0.1%≈年化 -3pp）
3. 操作完记账：
   ```bash
   python3.8 record.py buy 518880 9.10 50000   # 代码 价格 金额(元)
   python3.8 record.py sell 518880 9.25        # 卖出全部
   python3.8 record.py status                  # 查持仓/盈亏
   python3.8 record.py history                 # 操作流水
   ```
4. 或直接把成交告诉我，我来记

## 纪律（最重要）

- 信号与判断冲突时，**执行信号**。震荡市连续小亏是策略成本，不是策略失效
- 不空仓焦虑：熊市持货币ETF就是策略的一部分收益来源
- 单次投入固定金额，盈利定期取出或并轨，不随意加仓
- 回测好 ≠ 未来好：前两个月是执行验证期，建议先用小仓位跑顺流程
