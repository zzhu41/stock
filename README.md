## 策略做什么

原11只ETF中一次持有一个标的，不加杠杆：

| 代码 | 名称 | 角色 |
|---|---|---|
| 159915 | 创业板ETF | 境内股票 |
| 588080 | 科创50ETF | 境内股票 |
| 510300 | 沪深300ETF | 境内股票、市场状态基准 |
| 510500 | 中证500ETF | 境内股票 |
| 563300 | 中证2000ETF | 境内股票 |
| 512400 | 有色金属ETF | 境内股票 |
| 512890 | 红利低波ETF | 境内股票 |
| 513100 | 纳指ETF | 跨境 |
| 513120 | 港股创新药ETF | 跨境 |
| 518880 | 黄金ETF | 黄金 |
| 511880 | 货币ETF | 现金停靠 |

1. **排名**：25日时间加权线性回归相对斜率乘250，除以20日日收益标准差，再取最近 **4个实际报价** 的分数均值。风险资产至少270个实际报价后才参与。
2. **市场状态**：沪深300在180日均线上方视为牛市；熊市限制境内股票持仓。动量仍用20日，沿用原牛/熊入场门槛与黄金/跨境后备规则。
3. **健康轮动**：普通换仓最短持有2个市场交易日，并保留境内/跨境/黄金分别2/3/3个百分点的动量缓冲。急跌、趋势失效等退出例外沿冻结策略。
4. **急跌阈值**：使用该ETF **前一实际报价日** 的20日与60日波动较大者，乘 **1.4**，限制在2%—10%。评分仍用自己的原波动分母，不把该风险尺度重复套入排名。
5. **抄底**：保留深跌与放量通道，关闭QVIX通道；抄底实际入场后锁仓5个交易日，锁内急跌退出开关保持关闭。保留原过热过滤与后备资产规则，后备资产也可能是负动量跨境ETF或黄金。

相对C4，这个版本只把急跌风险倍数从1.25改为1.4。它提高了已知历史全期年化，但2021仍偏弱，不能视为已经解决震荡和过拟合问题。

## 每日推送与“动量”查询

- 14:47预热；14:50开始生成，14:52/14:54重试未成功的生成或未确认送达的同一信号。生成、发送与报价时效均有截止限制。
- **第一张卡为V12-R2主推送**，目标代码与名称加粗；后面依次为V9.2、V9.2+、V10-H对照。
- 新主账户从首次有效实时信号以净值1开始，最早2026-09-29。研究回测、其它策略账户和个人真实持仓都不接入它的净值；没有有效信号时明确等待，不填历史目标作买入建议。
- 新主版本失败时明确显示“主推送本次无有效建议”；对照版本成功也不会成为新主版本的替代目标。监控会识别这种降级。
- 主动查询只读保存记录，不推进账户、不发起交易。过期、窗口外或失败信号标为历史，不补追。
- 本系统产生信号和独立虚拟跟踪，**不自动下单**；`portfolio.json`与`trades.csv`个人账本独立维护。
