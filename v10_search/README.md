# v10-H：大规模枚举与牛熊门消融

本轮已完成 **5,156个不同配置**，全部先在2014–2021开发期计算并冻结选择，再复算2014–2026-09-11完整路径，共10,312条主候选回测。另有控制、成本、窗口、同收盘及搜索统计诊断。原v9/v9.1/v9.2、前两轮研究和生产数据/账本共209个受保护文件哈希未变。

**结论：发现了更高的历史收益配置，也发现了更均衡的探索候选，但没有得到足以宣布“可靠强H”的证据。开发期冻结的赢家在后段失败，完整搜索校正没有支持超基准。**

固定主口径为次日开盘实际持仓反馈，单边佣金0.01%＋滑点0.10%，初始及全部成交收费，无杠杆。共同截止日由现有数据决定，没有改用当天收盘理想价格提高主排名。

## 去掉牛熊门到底如何

先固定原v9.1资产池、WLS25和其他参数：保留MA250体制净年化37.69%；启用原`bear_open_stock`开关33.14%；固定原牛市路径、忽略体制32.94%；股票、跨境、黄金全部统一竞赛28.77%。因此直接去门控没有改善原配置。

39.08%的探索者同时改变了池与窗口：A股只留159915/510300/510500，另有513100、518880和货币511880，WLS30。熊市允许强势A股参赛，但仍保留7%进场门、急跌、过热、缓冲、永不空仓与原深跌抄底。它不等于彻底取消牛熊判断。

`bear_open_stock`的原有语义还会改变黄金角色：熊市通常由股票与跨境竞赛，黄金成为备胎/兜底，而非继续作为原熊市常规竞赛成员。完整配对表和三模式56组已登记对照统计见[研究报告](results/REPORT.md)。不能把整个组合的提升全归功于去掉一个门槛。

## 三个可运行的研究配置

```bash
# 开发期预先冻结的选择；后来相对表现失败，完整保留。
python3.8 -B -m v10_search.cli backtest growth

# 全历史最高收益者；明确是后见探索配置。
python3.8 -B -m v10_search.cli backtest exploratory

# 回应去牛熊问题的开放熊市小池探索者；不是开发冠军。
python3.8 -B -m v10_search.cli backtest regime
python3.8 -B -m v10_search.cli signal regime --end 2026-09-11
```

信号输出来自历史模型账户，日期明确；不获取实时行情、不读取真实持仓、不推送或下单。可用`--data-dir /path/to/csv --end YYYY-MM-DD`显式提供新的完整、同一复权口径CSV，只读复算；默认仍是冻结快照。输入CSV无表头，列为date/open/close/volume。公开配置逐项校验实现、依赖、配置和研究档案哈希。

## 重现及矩阵归档

Python3.8+和NumPy；绘图另需Matplotlib。本机两核，默认2个搜索worker；先做实际持仓的通用引擎保真，避免把加速错误当收益。验证脚本比较三个控制全3088日与旧不可变路径，最大净值误差约1.32e-12；另有18配置×3窗口的原函数oracle、独立原始指标和同收盘检查。

```bash
python3.8 -B -m unittest discover -s v10_search/tests -v
python3.8 -B -m v10_search.verify_fidelity

# 选择已存在时develop拒绝覆盖；重新搜索请另存新批次并保留原档案。
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3.8 -B -m v10_search.scan develop --workers 2
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3.8 -B -m v10_search.scan evaluate --workers 2

```

原始收益矩阵约77MB和122MB。为便于保存，提供逐字节无损`.npy.gz`归档，原始`.npy`不进入Git；本工作区仍保留可直接使用的原始矩阵。若从版本副本恢复，先运行：

```bash

```

恢复会验证归档与原始字节哈希，不重新挑列或转换精度。`matrix_archives.json`记录大小与校验值。
