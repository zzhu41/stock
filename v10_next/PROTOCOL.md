# v10_next：本轮候选与验证协议

锁定日期：2026-09-27。范围：隔离的新研究目录 `v10_next/`。本轮目标是形成两条可审计的研究路线：高收益且尽量简单；稳健且尽量减少研究选择自由度。没有合格改进也应如实交付，不为凑出两个赢家扩大搜索。

**这里“预先锁定”只表示本轮结果产生前固定规则，不表示过去从未见过这些数据、资产或机制。全部历史区间已参与过项目研究，任何部分都不得标为真正未见OOS。** 文献依据及其局限见 [LITERATURE.md](LITERATURE.md)；此前研究选择审计见 [research_selection_audit.md](../reports/research_selection_audit.md)。

## 1. 隔离和数据边界

- 只在 `v10_next/` 新建研究实现、配置、测试和报告。现有v9、v9.1、v9.2及旧 `v10/` 文件、生产信号、定时任务、行情缓存和账本一律保持不变。
- 读取现有本地CSV，不联网补数据，不调用行情更新、推送或实盘记账函数。候选不依赖QVIX、两融或成交量恐慌源。
- 本地511010国债ETF数据仅到 **2026-09-11**；本轮所有候选和控制统一 `END=2026-09-11`。不把债券旧报价向后填到09-24，也不让其他版本多跑两周后直接比较。
- 固定输入文件、标准化数据内容哈希、代码哈希、候选配置、执行成本、起止日和协议哈希。复权历史修订不视为同一份数据；若发生修订，保留旧报告并重新标明数据版本。
- ETF仅在已有历史且满足其信号预热长度后进入可选集合。没有历史的资产不伪造价格，不补造预上市数据。资产纳入日期和各期有效池大小必须报告。

## 2. 候选预算：7个非控制，3个控制

本轮仅下表10行可以进入正式结果矩阵。不得根据表现增加候选、删除失败候选、把邻域赢家升级为第8个候选，或把消融项临时交叉组合成新版本。修复实现错误不增加机制预算，但须说明修复影响并重跑全部受影响比较。

### 三个控制

| ID | 固定定义 | 用途 |
|---|---|---|
| `control_v9` | 修复后v9规则；统一2%缓冲 | 版本参照 |
| `control_v91` | 修复后v9.1规则；A股/跨境/黄金2%/3%/3%缓冲 | 高收益路线主要对照和允许的回退选择 |
| `control_v91_half` | v9.1风险资产目标仓位固定50%，其余货币；本来持货币时全为货币 | 简单仓位压缩参照，不参与高收益路线冠军选择 |

三个控制均由隔离实现复现，并使用本轮统一的下一交易日开盘、逐边费用及实际持仓记账。不能用旧同日收盘理想收益替代此对照。`control_v91_half`只能说明仓位压缩的贡献，不会完全隔离择时和组合结构的因果作用。

### 高收益、简单路线：4个候选

未列出的规则均继承 `control_v91`。保留现有牛熊开关、急跌保护等默认行为；不额外扫阈值或增加外部数据。

| ID | 相对v9.1的唯一预先指定变化 | 本轮假设 |
|---|---|---|
| `h_no_crash` | 关闭深跌抄底及其锁仓分支 | 移除少数危机事件驱动的反转层，检验趋势核心的净成本收益 |
| `h_no_bear_gate` | 熊市新进场MOM20门槛由7%降至0；A股牛熊禁入规则保留 | 删去额外强度门槛，不等于全面开放熊市A股 |
| `h_ensemble` | 排名改为WLS20/25/30三个窗口的固定等权平均，沿用相同VOL20标准化 | 减少只依赖WLS25一个窗口的敏感性；不再选择最优窗口或学习权重 |
| `h_core_pool` | 风险池固定为159915/510300/510500/513100/518880，货币仍为511880 | 移除较新主题和部分行业基金；按预先固定池比较，不根据本轮收益增删成员 |

`h_core_pool`的角色映射固定：159915/510300/510500为A股、513100为跨境、518880为黄金。旧11只池也曾经过大量研究，因此缩成核心池不能被宣传为消除了全部事后选池偏差。

### 稳健路线：3个候选

固定风险资产池：**510300 / 510500 / 513100 / 518880 / 511010**；货币停靠：**511880**。不加入深跌抄底、QVIX、量能通道、固定4%急跌保护、过热门、熊市7%门、WLS回归或根据后期表现改变的例外规则。

固定决策时点为**每个月第一个实际可见交易日收盘**；目标在**下一交易日开盘**执行。不是月末调仓，不回填当月后续数据，不因“这个月末收益更好”改变日历。

| ID | 信号 | 持仓 |
|---|---|---|
| `r_m12_top2` | 过去244个交易观察期累计收益，收益必须严格大于0才合格 | 按动量排序选前2；每个名额50%，不足名额留货币 |
| `r_multi_top2` | 61/122/244日累计收益的固定算术平均，均值严格大于0才合格；不学习三个权重 | 选均值排名前2；每名额50%，不足部分留货币 |
| `r_m12_broad` | 每个资产自身244日收益严格大于0 | 五个资产各预设20%名额；某资产不合格时其20%放货币，不转给其他赢家 |

所有使用窗口按实现中一致的交易日/有效观察期定义并记录；遇缺行情不可把陈旧行当成当日信号。Top2只有一只合格时不是100%集中到该资产。信号同分用固定代码字典序，不用未来收益破平局。月内持仓随市值漂移；仅在既定调仓时点重置目标，不免费每日再平衡。

“每资产20%”不是每风险因子等权：510300和510500同属中国权益，共40%的名额；不把五个资产声称为五个独立风险来源。

## 3. 时间分区与揭示顺序

| 区间 | 本轮用途 | 明确禁止 |
|---|---|---|
| 2014-01-01—2021-12-31 | Development，开发和事先限定的模型选择 | 不在看到后段结果后重新定义开发赢家 |
| 2022-01-01—2025-12-31 | Chronological validation，已见历史的顺序验证 | 不称真正OOS；失败后不换挑第二名再宣称通过 |
| 2026-01-01—2026-09-11 | 只报告；不参与选择、门槛调整或机制修改 | 不因为2026好看而推广，也不因不好看而补规则 |

顺序：先保存本协议和候选配置，完成开发期计算及下述选择；写出所选ID与选择依据，再展示2022–2025与2026。验证失败可以导致“不推荐”，不能触发本轮追加搜索。

允许为指标预热读取2014年前数据，但不计为开发期策略收益。采用连续持仓路径划分区间，跨年边界的隔夜收益归入其实际实现日；各子区间收益以其开始前的已计量净值为基准。不能从子区间第一天收盘归一而漏掉第一天损益。另行从现金重新启动只能作为明确标注的启动敏感性，不能混入主要选择分数。

## 4. 结果前固定的选择规则

主选择口径：实际持仓按次日开盘执行；**单边佣金1bp + 单边滑点10bp**，不使用同日收盘理想成交结果选型。年化按244个交易日；所有指标来源于同一条扣费净值。

### 高收益路线

在开发期同时满足以下约束的4个高收益候选及 `control_v91` 中，选择净CAGR最高者：

1. `abs(max_drawdown_candidate) <= abs(max_drawdown_v91) + 0.05`，即最大回撤最多恶化5个百分点。
2. 发生实际调仓的年均交易日数不超过v9.1的1.25倍。

年化相同仅按数值精度相等判断，先选机制更少者，再选换手更低者，再按固定ID顺序；不新增“相差一点也算赢”的事后容差。`control_v91`可以胜出，届时明确报告高收益路线没有合格改进。基线失败或实现保真不通过时停止选型，不能把失真的对照当成门槛。

### 稳健路线

在3个稳健候选中，先检查：

1. 开发子段2014–2017与2018–2021的净CAGR，均**严格高于同期511880买入持有的CAGR**；只“绝对收益为正”不够。
2. 全开发期绝对最大回撤不大于 `control_v91`。
3. 发生实际调仓的年均交易日数不超过30。

合格者按 `min(Calmar_2014_2017, Calmar_2018_2021)` 最大选择；Calmar定义为该子段净CAGR除以绝对最大回撤。最大回撤为0或无法计算时，该子段Calmar不得以无穷大参与排名，候选不满足可排名条件。分数同值依次选择规则更简单、换手更低者，最后按固定ID顺序。

若均不合格，交付三个候选及失败原因，稳健路线结论为“尚无合格版本”。不得临时放松货币超额、回撤或交易条件。选型中的半仓对照、现金占比和风险资产暴露必须一并展示；不把低收益低暴露本身解释为低过拟合。

## 5. 执行和工程保真

- 开盘执行时，卖出旧持仓前仍承担其隔夜收益；成交后持有新资产承担日内收益。每个实际买卖方向扣费，初始建仓也收费；多资产再平衡按变动金额扣费，不按“只换一个名字”计费。
- 实际持仓、待执行目标、现金、估值和信号状态明确区分。延期成交后后续决策必须读取实际持仓；若仅重放预先计算的目标序列，只能标为固定目标执行敏感性，不可冒称完整执行感知回测。
- 没有有效当日开盘价时不能假设成交；对应交易延期并记录。缺报价持仓以最后实际价格暂估，报价恢复后补计整个未计价区间；不能永远抹去缺行期间收益。
- 对非正、NaN、无穷、重复日期、未来日期和混合复权等异常失败报错，不能把非法价格自动变成零收益。缺少必要ETF或债券覆盖时不能静默换资产或延长数据。
- 小合成样本核验信号滞后、隔夜/日内记账、现金余额、初始费用、双向交易费用、月初触发、Top2不足两只、复权及缺行恢复。
- 在可比的无缺行、相同执行约定下验证控制实现与固定v9/v9.1行为；若实施时点或记账口径不同，列出差异，不能用预期不一致的终值当保真通过。

## 6. 稳健性报告与额外运行预算

以下是预先指定的诊断，不是用于挑选新候选的搜索空间。每次运行仍要进台账，不能因为叫“诊断”就隐藏它；7个正式候选上限不等于全项目只有7次统计尝试。

1. **成本敏感性：** 正式矩阵使用10bp滑点；同一10行矩阵另报5bp、20bp、50bp单边滑点，佣金仍1bp。最多30个额外成本情景，保留全部结果，不选最有利情景作主结果。
2. **窗口邻域：** 只对已选定的两条路线做单轴±10%窗口尺度诊断；所有同族窗口同步按固定倍率缩放并取最近整数，不交叉扫门槛、池子、调仓日或止损。最多4个额外配置，只展示原版本是否处于孤峰，不替换所选ID。若该路线无窗口参数，不补造其他旋钮。
3. **缺数据：** 在合成样本验证缺行情行为；真实报告列缺行、延期交易次数和受影响区间。不挑几个表现好的缺失情景作为验证，也不事后用其他数据源拼接来修饰收益。
4. **集中度：** 逐年、分资产/类别贡献、最佳5/10/20日贡献、危机事件与持仓占比。删除最佳日或年份只是固定路径归因，不能说成实际可交易的新策略。
5. **暴露与换手：** 所有版本报告平均风险资产暴露、平均现金占比、年化波动、最大回撤、净CAGR、Sharpe/Calmar、实际调仓日、买卖腿数与金额换手。调仓日是统一选型计数；另报 `sum(abs(交易权重变化))` 的双向金额换手，不能与单边口径混用。市值被动漂移不计为交易。

成本和邻域诊断可以提示“优势很脆弱，因此不推荐”，但不能变成查看2022–2026之后改选邻域赢家的入口。所有阈值、成本、窗口和池子均由本次协议固定；新的想法另开后续研究批次并继承已经看过哪些数据的记录。

## 7. 输出必须说明什么

- 保存10行全部开发结果、两支选择ID和选择时间，再保存验证期和2026报告，不能只留胜者曲线。
- 同时列开发约束是否通过，以及验证期收益、回撤、成本退化和贡献集中情况。不把“通过开发门槛”与“已证明未来有效”混为一谈。
- 提供机器可读的配置、逐日净值/持仓、实际交易、延期事件、数据覆盖和哈希；给出一条离线复现命令。
- 不报告无法支持的精确全项目PBO、选型校正显著性或未来盈利概率。配对区块bootstrap若使用，注明仅描述已选路径的条件不确定性。
- 不自动修改生产策略或部署。研究输出最多确定下一步应冻结并跟踪什么；新的未来记录仍需要独立保存。

这个协议限制本轮继续试错的自由度，并使失败可见；它不会把2014–2026已被研究者反复查看的历史变成干净样本外数据。
