# V12 历史重选证据

[结果说明](REPORT.md)：四次训练保留全部1807个配置，2017/2019/2021/2023合格数量为70/24/24/0，最后一折按协议回退H。2018—2025主收盘口径年化53.6134%，低于固定H的54.6618%；延迟一天有改善，但跨折不稳定。这不是干净样本外验证，也没有新策略晋级或部署。

- registration.json 与 registered_candidates.json：训练前冻结的候选、规则、日期及源码/输入哈希。
- folds/：每个截止日期的完整四情景路径、指标及选择，不读取后期收益选型。
- training_summary.json：四次训练的冻结选择；全部为单持仓。
- execution/：真实连续账户的逐日路径、决策、成交和模型边界记录；不拼接独立回测净值。
- evaluation.json：四情景逐年/分段结果，以及16个H训练前缀收益和持仓逐值一致的证明。
- continuity_audit.json：8个实际账户情景、16个换段边界和2304笔成交费用核对；保留持仓、净值、年龄、锁仓及峰值，只有整个账户首日免费。

冻结入口为 python3.8 -B -m v12.reselection，参数 --phase register、train、execute 分别执行一个阶段；不要对已有冻结输出覆盖运行。新增重选测试为 v12/tests/test_reselection.py，7项纯合成测试已通过。本目录为研究证据，不会更新生产账户。
