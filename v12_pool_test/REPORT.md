# V12-R2 池扩展实验：加入恒生科技 ETF(513130)

**日期：2026-10-11 · 结论：不建议加入。主口径年化 55.27% → 51.74%,2023–2026 连续四年跑输原池。**

## 方法（只读隔离，未改动任何原文件）

- 基线：冻结的 V12-R2 主推送候选 `v12r2_08b522c2e1aa291f054d` 原配置、原 24 资产冻结特征矩阵(`v12_r2/results/features.npz`,SHA 校验）。
- 引擎：独立 Python 参考状态机 `v12.reference.run_reference`。**基线逐日收益与冻结 `paths.npz` 的 close_1bp 路径逐位一致(array_equal)**,holdings 同样逐位一致；扩展矩阵+原池配置也逐位一致，因此全部差异只能来自 513130 被纳入交易池。
- 新资产数据：513130(华泰柏瑞南方东英恒生科技 ETF,QDII)腾讯日线 2021-06-01 — 2026-09-24,1293 个报价日。该基金自成立以来无分红无拆分(腾讯无复权序列；天天基金/理杏仁分红拆分页均为空）,TR 序列按零公司行为重建(`total_return_audit.reconstruct_total_return`,caller-verified 空事件表）。
- 特征列：复刻 `v10_deep.features` / `v12.diagnostic_features` 冻结算法；**先用同一代码重算老资产 513100 与冻结矩阵对比，28/28 项通过**(非覆写特征全期逐位一致；覆写特征在 legacy 数据截止后 ≤1e-12;WLS25/WLS20S3 冻结有效区逐位一致），才用于 513130。
- 270 个自身报价后才可入选（513130 实际 2022-09 起才可能入选）,2014–2021 逐年差异恒为 0。
- 数据截止 2026-09-24，同研究口径：修正总回报、理想同收盘、首日免费、244 交易日年化。

## 513130 实际交易（close_1bp,140 天 20 段）

- 段收益（含费用与切换日）13 盈 7 亏，算术合计约 +34%，最好 2022-11-14→12-30 共 35 天 +14.0%（恒生科技 2022 年底大反弹）;2022 年 +6.27pp 几乎全部来自这一段。
- 但**段内盈利 ≠ 组合贡献**：它替换掉的往往是原池同期更强的持仓。2024 年 513130 五段合计约 +21%，年度却差 -23.26pp——替换掉的是 513100/513120 当年更强的行情。
- 2026-07-17 单日 -6.25%：深跌抄底通道接刀失败，次日规则退出。

## 判断

1. 主口径与手续费压力口径下，两个池位都是负贡献；lag1 口径的微升来自路径扰动而非稳定增益，且 lag1 不是部署口径。
2. 负贡献集中在最近三年（2023 -8.7pp / 2024 -23.3pp / 2025 -15.4pp)，不是早期噪声。
3. 港股敞口已由 513120（港股创新药）承担；513130 与 513100/513120 动量信号高度同频，只增加换手（+16 次），不提供分散。
4. 结论与既往封盘纪律一致：**池维持 11 只不变**。本实验目录仅为证据，未接入任何生产链路。
