# v10 第二轮：收益目标与选择协议

锁定日期：2026-09-27。此文件须在第二轮开发结果产生前与候选配置、实现及数据哈希一起保存。

**这是第二轮研究。第一轮全部候选、成本、窗口诊断及失败结果已经公开；本项目2014–2026历史也早已被研究者查看。本轮预先锁定只约束接下来的运行，不代表数据或机制从未被看过，不得称为真正未见样本外检验。**

本轮按用户新的目标，寻找H路线超过v9.2、S路线净年化至少30%的候选。上一轮S强调低回撤和月度分散，本轮S强调收益下限与减少选择自由度，二者验收目标不同。不能将上一轮失败的配置改名后说成上一轮已经通过，也不保证本轮一定找到达标版本。

## 1. 隔离、数据与主要执行口径

- 第二轮新增实现、配置、测试和结果只写 `v10_round2/`。不改现有v9/v9.1/v9.2、旧 `v10/`、第一轮 `v10_next/`、生产推送、缓存或真实账本。
- 沿用第一轮冻结的本地ETF价格快照；QVIX仅从已有本地文件截取并复制到第二轮目录，保存源与副本哈希。不联网补行情或改变原数据。
- 所有9项统一使用 **2014-01-01至2026-09-11** 的可观察交易日；允许读取更早历史预热，不计为研究期收益。不让某候选多跑两周后与另一个候选比较。
- 主口径：当日收盘数据形成目标，下一可成交交易日开盘执行；按实际持仓、单位数、现金和延期结果更新后续决策。**单边佣金1bp + 单边滑点10bp**，初始建仓及每条实际买卖腿收费，禁止杠杆和隐性现金借款。
- 危机锁仓按实际确认成交时点计数。没有报价不假设成交，持仓估值暂用最后有效价，恢复报价后补计损益；缺行与延期必须留痕。
- v9.2控制使用原三通道并集：原深跌、QVIX恐慌、量能恐慌。QVIX标准化仅用此前窗口，当日缺值时停用该通道；量比使用当日量与此前20日均量。历史QVIX发布时间不可验证，“收盘值在下一开盘前可用”是本轮假设，不据此声称14:50已经可见。

**H比较对象必须是本轮同快照、同截止日、同引擎、同成本的 `c_v92`。** 第一轮v9.1的37.69%与旧报告v9.2的36.47%使用不同截止日和延期后的决策方式，不能据此直接判H已经胜出。

## 2. 正式预算：9项，禁止追加搜索

本轮共2个控制、3个H候选、4个S候选。只有下表可参与开发选择；不得跑后增加新阈值、组合、资产池或备用候选直到达标。全部结果和失败原因保留。

### 对照

| ID | 固定定义 |
|---|---|
| `c_v91` | 修复后v9.1参数与规则，在本轮实际持仓执行器中重建 |
| `c_v92` | 在相同v9.1普通轮动规则上加原深跌∪QVIX∪量能三通道；同一执行器与锁仓语义 |

### H：超过v9.2

| ID | 固定定义 | 相对c_v92的变化 |
|---|---|---|
| `h_qvix_only` | 保留原深跌与QVIX通道，普通规则保持v9.1 | 删除量能通道；名称中的only不表示删除原深跌 |
| `h_v91_no_overheat` | v9.1规则，过热阈值设为9.9（990%）作为本轮禁用代理，同时影响过热进场禁止和快速离场 | 没有QVIX/量能通道；不是对所有理论价格路径完全删除分支，其余不变 |
| `h_qvix_score25_30` | 原深跌∪QVIX，排名为WLS25/30分数的固定算术平均 | 删除量能通道，不学习窗口权重；沿用VOL20尺度 |

`c_v91`也允许进入H路线选择集合。如果它在本轮同口径下已超过c_v92，可以作为H选择，但必须称为原v9.1规则的回退，不能包装成发现了新增Alpha。

### S：净年化至少30%，尽量减少选择自由度

| ID | 固定定义 |
|---|---|
| `s_v91_wls30` | v9.1规则，仅排名WLS窗口固定为30 |
| `s_v91_wls30_no_crash` | 上项同时删除原深跌抄底与锁仓分支 |
| `s_accounts25_30` | 两个独立v9.1规则账户，WLS分别25/30；初始资金各一半 |
| `s_accounts20_25_30` | 三个独立v9.1规则账户，WLS分别20/25/30；初始资金各三分之一 |

独立账户版本不是分数平均，也不是每日把账户净值重新等分：各自持仓、现金、待执行目标和锁仓状态独立；不在账户间补仓、转移盈亏或定期再平衡。组合净值为真实账户资金之和，不能平均各账户CAGR。每个账户实际成交额独立计费；不因组合层抵消买卖方向而事后免除费用。

本轮S候选仍继承不少v9.1历史规则；只有明确删除的分支才算被移除。固定多个相关窗口不等于多个独立证据，也不意味着全部规则更简单。登记表应说明哪些机制/配置此前已研究或看过结果，不能因为换了目录而标为首次发现。

## 4. 开发期选择：先筛选，后排序

主要指标均为扣除1bp佣金与10bp滑点的实际持仓路径；CAGR按244个交易日年化。下面DD用绝对最大回撤幅度，`+0.02`表示**2个百分点**，不是乘以1.02。

### H选择

集合：`h_qvix_only`、`h_v91_no_overheat`、`h_qvix_score25_30`、`c_v91`。

开发期同时满足：

1. `CAGR_H > CAGR_c_v92`，严格大于，不能把持平记为胜出。
2. `abs(DD_H) <= abs(DD_c_v92) + 0.02`。

合格者依次按**更高净CAGR、较少外部通道、较低累计金额换手、固定ID字典序**排序。外部通道按本轮候选依赖计数：无QVIX/量能为0，仅QVIX为1，两者都有为2；这里是事前解释性破平局，不是独立因子数的统计估计。

如果没有合格者，H选择为空，报告没有找到达标候选；不能把c_v92本身作为“超过自己”的胜者，也不能补加模型。

### S选择

集合：四个S候选。开发期同时满足：

1. `CAGR_S >= 0.30`。
2. `abs(DD_S) <= abs(DD_c_v92)`。

合格者依次按**更低绝对最大回撤、较低累计金额换手、固定ID字典序**排序。这里不按最高全样本CAGR挑S，也不临时加入夏普、Calmar、单年门槛或给某个已知候选的豁免。

如果没有合格者，S选择为空，保留四项结果并如实报告失败。30%是本轮历史净CAGR目标，不是未来收益承诺；满足它也不证明低过拟合。

### 交易统计口径

金额换手按全部实际成交参考金额除以对应时点总组合资产计算，买与卖均计入；独立账户应按当时资金占比合成，不直接相加各子账户的归一化换手。组合调仓日按“当天任一账户实际成交”去重，另报买卖腿数和各子账户交易。开发选择所用换手必须只包含开发区间。

## 5. 冻结后的验收标签

默认采用**次日开盘实际持仓、1bp佣金+10bp滑点**，不是同日理想收盘。

| 标签 | H | S |
|---|---|---|
| 主收益目标达标 | 2014至统一END全程净CAGR严格超过同区间c_v92 | 同区间全程净CAGR至少30% |
| 强化跨期支持 | 2022–2025净CAGR也严格超过同期c_v92 | 2022–2025净CAGR也至少30% |

只有开发期先冻结的ID接受这两项检查。全程达标但强化跨期未达标，写成“总样本达标，跨期未支持”；不得隐藏失败，也不得在验证期挑第二名代替。开发期无人合格时，后段即使某项很好，也只能报告其结果，不能追认它为当时已选赢家。

2026单独报累计收益及回撤，不设短期年化硬门槛，不通过2026结果改变已冻ID。所有DD、波动、现金暴露和集中度照常报告；开发期风险门槛不等于未来或后段回撤上限保证。

关于是否同日理想收盘也必须胜出，用户尚未另行明确，本轮公开采用上述次日开盘主口径。同收盘只做下节诊断；不能在看到哪个口径更好后切换主要验收定义。

## 6. 有限诊断预算，禁止诊断赢家晋级

1. **额外成本：** 全9项各跑20bp和50bp单边滑点，佣金仍1bp，共18个额外成本情景。10bp为唯一默认选型口径，不挑低成本档替代主结果。
2. **同日收盘理想情景：** 全9项统一报告，单边佣金1bp、滑点0。使用全日价格/QVIX/成交量形成信号并假设该收盘成交，存在理想化和发布时间限制；它不是历史14:50可执行重建，也不进入本轮默认选择或主验收。
3. **窗口邻域：** 只对已选H/S各做同族窗口整体×0.9与×1.1，取最近整数，每支最多2项，总计最多4项。分数集成或独立账户的全部WLS窗口同步缩放，固定原权重；不另扫通道阈值、池子、持仓天数。选择为空时不为其补跑候选。邻域仅报告，不能替换冻结ID。
4. **配对历史重采样：** 如使用区块bootstrap，只检验预先冻结路径相对c_v92的增量稳定性。两条路径同步采样、保留尾块正确样本长度、区分CAGR差与相对收益；公布种子、块长和次数。结果是条件于这些已选路径的诊断，不是全项目PBO、无过拟合概率或未来超额收益保证。
5. **风险与集中度：** 全部候选报告DD、波动、费用、金额换手、现金与风险资产暴露、逐年收益、危机交易及最佳日贡献。删除最佳日或年份只做归因，不冒称可交易新策略。

以上额外运行都记录在本轮台账，不能称为“没有尝试过”。它们不新增正式候选，但也不能抹去第二轮及上一轮已经消耗的历史信息。

## 7. 允许与不允许的结论

允许的结论是：某个事先限定候选是否满足本轮历史收益门槛、跨期支持如何、是否减少特定分支或数据依赖、对成本和窗口是否敏感。

“尽量减少过拟合”只通过有限预算、删去稀有事件依赖、减少条件分支、固定等权平均、保留失败项和检查跨期/成本/邻域来执行。单纯提高历史收益、选择WLS30、合并几个高度相关账户或把回撤压低，都不能证明过拟合已经降低到某个概率，更不能承诺被消除。

不允许的结论包括：把已见2022–2025称为真正OOS；把2026好看当作调参理由；把不同截止日或不同撮合引擎的数字作为H胜v9.2证据；把仅在理想收盘胜出说成默认次日开盘达标；在结果失败后扩候选直到实现30%；自动修改或替换现有生产版本。

若代码错误影响结果，修复后记录原输出、代码差异和新指纹，重跑受影响矩阵；不能借修复改变候选定义或删掉失败记录。最终交付完整注册、开发、选择、验证、诊断及可复核路径，并明确哪些目标没有达到。
