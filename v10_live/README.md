# V10-H 影子信号接入

每日 `daily_job.py` 为正式生成施加90秒整体时限；`signal_daily.py` 调用最多60秒的 `daily_extras`，统一取得总回报/原始行情/行动视图及封存QVIX快照。当前V12-R2为主推送，V9.2、V9.2+、V10-H保留为对照。worker只修改隔离账户副本；主进程在报价/窗口通过最终核验后，将四版本文字及成功账户一起提交到schema2 `signals/daily_state.json`，再恢复账户/文字投影。查询只读、不计算或推进账户。个别版本失败只显示本版本错误；主版失败不回退对照目标，全部失败则不发布新卡。

接入的是冻结研究 H `vd_7d52c290adc6c4503f7d`，规则和研究依据见 [研究报告](../v10_deep/REPORT.md)。尚未选出达标的新S，所以没有把未达标的研究对照上线为S。原11只ETF池，WLS20评分取3日均值、MA180体制、1.5倍VOL20急跌退出（2%–10%），其余沿用原框架。原始研究目录的 `live_enabled=false` 是冻结时的历史状态，本目录新增的能力仅为独立影子观察。

## 数据与记账

- `data.py` 从冻结的修正总回报快照及匹配原始价格开始，在 `data/v10_live/` 独立缓存增量；不使用或改写旧版前复权缓存。schema2按每只资产自己的实际报价推进，兼容旧cache。已确认缺报价区间没有公司行动时，复牌后可恢复，账本在缺日保持份额；不补造可成交价格。跨缺口现金行动无法定位时仍需人工核验。
- 同一批原始/QFQ日线用于核验现金分红；当日用开盘价核验复权偏移，当前价格使用主脚本已取得的报价。不同请求的盘中收盘价不能相减推分红。未知拆分、行情缺失或不能确认的复权变化使本次H失败。
- 腾讯对563300、513120的复权请求目前返回 `day` 字段；仅在冻结和已确认历史无公司行动、完成日价格逐项相同、当日开盘及除权前收参考一致等检查全部通过时接受此格式。不能确认时仍停止本次H，不能把缺少复权字段普遍视为零分红。
- `policy.py` 核验冻结配置和研究依赖，复用独立参考策略；不修改根目录 `strategy` 参数。QVIX只读已有日期快照，当日不可用时明确停用该渠道，深跌/量能渠道继续参与盘中试算。
- `ledger.py` 用原始价格、实际虚拟份额和除息权利记账。从第一次有效当日信号以净值1独立开始，不承接历史回测或其他版本账户。首次建仓免费，之后换仓按总计万二计成本；同日重复调用返回首次保存记录。
- 除息前持有的旧份额才能领红利；当日新买入目标没有当天红利。虚拟现金红利在当日首个记账价再投资，漏运行日用该日已完成的原始收盘价再投资，不补造漏掉的策略交易。此为虚拟即时再投资约定，未模拟券商实际到账日、整手和成交限制。
- `signals/shadow_v10.json` 同时原子保存份额、净值、锁仓、事件和当天展示；文件锁阻止并发入账。提交后回复超时会只读恢复已保存的当天卡片。状态和临时文件不入Git。
- runtime在计算前、结算前及临时文件fsync后的replace前都独立校验报价时效和14:50–14:55窗口，共享缓存视图不能绕过。生产入口经每日staging/canonical事务提交，避免影子已入账而主卡因过期未发布。
- 若次日完成数据修订了已经入账的临时分红或拆分，暂停该账户并提示复查；即使当时已经换出该资产也会核对，不静默修改或重置净值。

14:50价格、累计量和QVIX可用性与历史最终收盘不同，因此卡片标明“盘中影子试算”。这条前向净值不能等同于研究回测或真实成交业绩。
