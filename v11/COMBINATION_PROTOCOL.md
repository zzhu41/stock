# V11-B 有限模块组合扩展（确认段解封前）

这是初始V11-A开发结果及其不显著统计诊断启发的一次自适应扩展，不是初始协议已事先列明的搜索，也不是新的干净样本外实验。V11-A的586族、选择结果、邻域以及失败证据完整保留，不覆盖；V11-B不能替代或粉饰A的确认结论。当前未读取任何新候选的2022—2025或2026绩效。

动机：单独更换评分不必然改善交易行为，论文关于多速度信号与成本下调整速度提示可检查这些机制的交互。本扩展只使用已经登记的机制，不增加新窗口、风险阈值、资产池或学习权重。

## 固定生成规则

从A的2014—2021结果按其原门槛（合格优先）及原最差/中位子段压力超额、换仓次数、复杂度、ID顺序选组件，组件抽取并去重：

- 评分：固定H与原WLS25；robust_regression、multi_horizon_consensus两族各前2个不同score（最多6个）。
- 风险：固定H；prior_risk_scale、fixed_risk_scale两族各前2个不同(panic_mode,panic,risk_context)（最多5个）。
- 健康换仓：固定H；healthy_momentum_retention、healthy_rank_retention两族各前2个不同buffer/min_hold/switch_confirm/rank_keep组合（最多5个）。
- 对三个组件做完整笛卡尔积，最多150个原始组合。其它条件固定H，不叠加新的稀有事件通道、不改MA180、不扩池、不加杠杆。

先保存全部组合和父组件凭据、代码/数据hash，再运行；旧A中已出现者计入重复，不作为全新发现。B的唯一主候选仍按A的同一开发门槛与排序确定，选择范围只在该150组合内，控制H不得冒名为新版本。A的原主候选继续独立保留，不合并成后验“只报告赢家”。

B选择冻结后，用同一邻域规则检查B（如与A重复则引用已有结果），再与A一起检查2022—2025和2026。后期表现不更改两个已冻结配置或门槛。报告本次扩展受到开发结果启发，条件性全族检验不能消除组件选取本身与历次研究的适应性偏差。

## 历史重选

B的历史重选必须在每个训练终点重新选A族组件、重新生成最多150组合并仅用该训练截止日评估B；不能把2021年选出的固定组件列表回填到2017。执行时仍连续维护实际持仓及费用；从2014用冻结H作起始模型、2018起按训练窗口选择，报告2018—2025连续执行段（初始H本身也是后见基准，必须说明）。A也用相同初始化及费用口径。

本扩展只产出研究候选；不以不显著或后验筛选的回测数字承诺未来收益，也不自动更改生产版本。
